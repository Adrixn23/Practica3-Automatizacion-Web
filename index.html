⚙️ Automatización del Flujo CI/CD

Push de Código al Repositorio

2
Pipeline de GitHub Actions

El flujo definido en .github/workflows/deploy.yml se activa, preparando el entorno y empaquetando los artefactos del sitio.

3
Despliegue Global en la Nube

GitHub Pages publica instantáneamente la nueva versión del sitio web con HTTPS asegurado y distribución en red de entrega de contenido (CDN).
