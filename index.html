⚙️ Flujo Automatizado de Integración Continua

1
Subida de Cambios (Push)

Al hacer un git push origin main, el repositorio detecta la modificación al instante.

2
Flujo de GitHub Actions

3
Despliegue Inmediato en la Nube

Los cambios se sirven globalmente vía HTTPS a través del hosting de GitHub Pages sin tocar ningún servidor.
